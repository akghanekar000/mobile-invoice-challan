# Invoice features

This branch adds basic invoice creation + PDF generation to the app.

Quick start

1. Install dependencies (if not already):

   npm install
   npm install pdfkit

2. Run Prisma migration (SQLite):

   # create a dev database path in .env
   DATABASE_URL="file:./dev.db"
   npx prisma migrate dev --name add_invoices

3. Start dev server:

   npm run dev

Pages

- /invoices/new — create invoice (mobile-first)
- /invoices/[id] — view invoice and download PDF

API

- POST /api/invoices — create invoice
- GET /api/invoices — list invoices
- GET /api/invoices/:id — fetch invoice
- GET /api/invoices/:id/pdf — download PDF

Notes

- The schema uses SQLite for local development. Change prisma/schema.prisma datasource if you use Postgres.
- Invoice numbering is autogenerated as `INV-<random>` by default; you can pass `number` in the POST to override.
